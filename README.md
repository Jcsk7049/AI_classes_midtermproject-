## 二、特徵工程視覺化

![特徵視覺化](feature_visualisation.png)

**說明：**
- **左欄（原始影像）**：輸入模型前的 64×64 像素彩色影像。
- **中欄（HOG 特徵視覺化）**：HOG（Histogram of Oriented Gradients，方向梯度直方圖）將影像的邊緣與形狀資訊轉換為熱圖。顏色越亮代表該區域有明顯的輪廓變化，可以看到蘋果的圓形輪廓、香蕉的彎曲弧線、柳橙的圓形邊緣都被清楚捕捉到。
- **右欄（HSV Hue 色相分布）**：統計每張影像在 HSV 色彩空間中，色相（Hue）值的分布直方圖。蘋果集中在紅色區域（Hue ≈ 0°）、香蕉在黃色區域（Hue ≈ 30°）、柳橙在橙色區域（Hue ≈ 20°），每種水果的色相分布明顯不同，是很強的辨識特徵。

**使用的特徵：**

| 特徵 | 維度 | 說明 |
|------|:----:|------|
| HOG | ~1764 | 描述影像輪廓與紋理方向 |
| RGB 顏色直方圖 | 96 | R/G/B 各通道 32 個區間，正規化後合併 |
| HSV 顏色直方圖 | 50 | Hue 18 個區間 + Saturation 32 個區間 |
| **合計** | **~1910** | 三種特徵串接後輸入模型 |

## 四、KNN 訓練過程

![KNN K值選擇曲線](knn_k_selection.png)

**說明：**
- **左圖（K 值 vs CV 準確率）**：對 K = 1 到 30 的每個值，使用 **5-fold 交叉驗證**計算平均準確率。藍色折線為平均值，藍色陰影區域為 ±1 標準差範圍，紅色虛線標示自動選出的**最佳 K 值**。
  - K 值太小（K=1）：模型只看最近一個鄰居，容易受雜訊影響（過擬合）。
  - K 值太大：考慮太多遠距離鄰居，導致邊界模糊（欠擬合）。
  - 最佳 K 值在曲線頂點，準確率最高且標準差最小。
- **右圖（Train vs Validation 準確率）**：
  - 綠色（訓練集）：K=1 時訓練準確率 100%（完全記憶），K 增大後降低，趨近合理值。
  - 紅色（驗證集）：隨 K 增大而先升後降，最佳 K 值使兩線最接近，代表模型泛化能力最佳。

## 五、SVM 訓練過程

![SVM Grid Search 結果](svm_gridsearch.png)

**說明：**
- **左圖（Linear SVM — C 值調整）**：測試不同正則化參數 C（0.01 / 0.1 / 1 / 10），長條圖高度為 5-fold CV 準確率，誤差條顯示各 fold 的標準差。C 值越大代表模型懲罰誤分類越嚴格（邊界越窄），過小則邊界太寬、準確率下降。
- **右圖（RBF SVM — C × Gamma 熱力圖）**：同時調整 C 與 Gamma 兩個超參數，數字為對應的 CV 準確率，顏色越深準確率越高。從熱力圖可以清楚看出哪個參數組合最佳，提供**視覺化的超參數搜索結果**。
- GridSearchCV 自動從所有組合中挑選最佳參數，再用完整訓練集重新訓練最終模型。

## 六、訓練曲線（Learning Curves）

![訓練曲線](learning_curves.png)

**說明：**
- 橫軸為訓練樣本數，縱軸為準確率，用來觀察模型在不同資料量下的表現趨勢。
- **左圖（KNN）**：
  - 訓練集準確率（綠）：樣本少時較高，隨樣本增加略微下降（因為更多樣本讓分類邊界更複雜）。
  - 驗證集準確率（紅）：隨樣本增加穩定上升，兩線最終趨近 → 表示模型**泛化良好**，無嚴重過擬合。
- **右圖（SVM）**：
  - 訓練準確率高且穩定，驗證準確率隨樣本增加快速上升後收斂。
  - 兩線間距小 → SVM 在此資料集上有良好的泛化能力。
- 若兩線差距很大（訓練高、驗證低）= **過擬合**；若兩線都很低 = **欠擬合**。本專題兩條線均收斂，表示訓練結果健康。

## 七、最終評估結果

### KNN 混淆矩陣

![KNN 混淆矩陣](knn_confusion_matrix.png)

**說明：**
- **左圖（原始計數）**：矩陣的列（Row）為**真實類別**，欄（Column）為**預測類別**。對角線數字越大越好（代表正確預測的數量），非對角線數字代表誤判。
- **右圖（正規化）**：將每列除以該類別總數，轉換為**各類別的正確率百分比**，方便跨類別比較（不受樣本數多寡影響）。
- 例如：若某格數值為「0.95」，代表該類別有 95% 的影像被正確分類；若非對角線有較高數值，代表兩類容易混淆（如橙色水果之間）。

### SVM 混淆矩陣

![SVM 混淆矩陣](svm_confusion_matrix.png)

**說明：**
- 解讀方式同 KNN 混淆矩陣，使用**綠色色階**方便與 KNN（藍色）區分。
- 比較兩個混淆矩陣可以看出哪個模型在哪類水果的辨識上表現較佳，以及哪兩類水果最容易被混淆。

### Accuracy / Precision / F1 比較

![模型比較](model_comparison.png)

**說明：**
- **左圖（分組長條圖）**：藍色為 KNN，紅色為 SVM，比較四項指標。每個長條頂端標示數值，越高越好（最高為 1.0）。
- **右圖（摘要表）**：列出每項指標的具體數值及「較佳模型」標記（✓），讓結果一目了然。

**指標定義：**

| 指標 | 定義 | 意義 |
|------|------|------|
| **Accuracy** | 正確預測數 ÷ 總樣本數 | 整體分類正確率 |
| **Precision** | TP ÷ (TP + FP)，加權平均 | 預測為某類時有多準確 |
| **Recall** | TP ÷ (TP + FN)，加權平均 | 某類實際樣本被找出的比例 |
| **F1 Score** | 2 × Precision × Recall ÷ (P + R) | Precision 與 Recall 的調和平均數 |

## 八、[積分題] 獨立載入模型預測

![積分題預測展示](bonus_prediction_demo.png)

**說明：**
- 此節完全**不依賴訓練過程的變數**，模擬真實部署場景：從磁碟載入 `.pkl` 模型檔案後直接預測。
- 每欄對應一種水果：
  - **上方**：輸入給模型的 64×64 像素影像。
  - **下方**：模型對四個類別的預測機率長條圖，紅色長條為最高機率（預測類別），藍色為其他類別。
- 標題顯示真實標籤與預測結果，✅ 代表預測正確，❌ 代表預測錯誤。

**命令列使用方式：**
```bash

python fruit_predictor.py --image banana.jpg --model knn
python fruit_predictor.py --image cat.jpg --model svm   # → ❓ 無此項目

```

## 九、[進階] 無此項目偵測（OOD Detection）

![OOD偵測展示](ood_detection_demo.png)

**說明：**
- OOD（Out-of-Distribution）偵測解決「模型被迫在已知類別中挑一個」的問題：即使輸入的是貓、車子或完全不相關的影像，傳統分類器仍會輸出某個水果類別。
- 本專題加入**信心度門檻（Confidence Threshold = 52%）**：
  - 若模型對**所有類別的預測機率都低於 52%**（紅色虛線以下），則判定為「❓ 無此項目」，不強制分類。
  - 若任一類別超過門檻，輸出該類別。
- 圖中三個輸入（隨機雜訊、灰色背景、深藍背景）模擬非水果影像：所有類別的機率條都矮於紅色虛線，因此全部正確回傳「無此項目」。
- 顏色為淺灰色的長條代表被判定為 Unknown 的狀態。

**運作原理：**
```
輸入影像 → 提取 HOG + 顏色特徵 → 計算各類別機率
  ├─ 最高機率 ≥ 52%  → 輸出對應水果 🍎 🍌 🍊 🍉
  └─ 最高機率 < 52%  → 輸出「❓ 無此項目」
```

## 技術架構

```
資料集 Fruits-360（每類 80 張，共 320 張訓練 / 140 張測試）
        ↓
特徵提取: HOG + RGB/HSV 顏色直方圖（約 1910 維）
        ↓
 StandardScaler 正規化（消除量綱差異）
        ↓
   ┌────┴────┐
  KNN       SVM
(5-fold CV)  (GridSearchCV)
(最佳 K 值)  (Linear / RBF 核函數)
   └────┬────┘
     評估比較
  Accuracy / Precision / Recall / F1
        ↓
   儲存模型（saved_models/*.pkl）
        ↓
  獨立預測 + OOD 偵測（無此項目）
```
